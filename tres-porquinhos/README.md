# Os Três Porquinhos — vídeo infantil (YouTube + TikTok)

## Versão atual: **v5** (vozes distintas + boca + atuação)
Personagens originais no estilo pré-escolar flat 2D, cada um com voz bem diferente e boca sincronizada ao áudio.

| Arquivo | Formato |
|---------|---------|
| `v5/output/tres_porquinhos_vozes_lip_youtube.mp4` | YouTube 1920×1080 (~5:34) |
| `v5/output/tres_porquinhos_vozes_lip_tiktok.mp4` | TikTok 1080×1920 |
| `v5/output/vozes_personagens.mp3` | Diálogo completo |
| `v5/output/vozes_amostra_5.mp3` | Reel das 5 vozes |
