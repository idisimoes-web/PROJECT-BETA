# Os Três Porquinhos — desenho falado (v3)

Episódio estilo **desenho animado de verdade**:
- Só os personagens falam (sem narrador)
- Cada um tem **voz própria**
- Close-up do personagem na tela
- Boca abre/fecha sincronizada com a fala (lip-flap)

## Duração
**~5 min 04 s**

## Personagens / vozes
| Personagem | Voz |
|------------|-----|
| Pipoca | Francisca aguda/rápida |
| Tambor | Antonio animada |
| Tijolinho | Antonio neutra |
| Mamãe | Francisca calma |
| Lobo Mau | Antonio grave/lenta |
