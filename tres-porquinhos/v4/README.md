# Os Três Porquinhos — estilo pré-escolar elaborado (v4)

Episódio no espírito de séries britânicas pré-escolares (tipo Peppa), com **personagens originais**:

- Corpo inteiro dentro das cenas (não bustos colados)
- Fundos suaves + personagens mais quentes
- Cortes de câmera wide / medium / close
- Personalidade visual e falas próprias por personagem
- Duração **~5:23**

## Arquivos
- `output/tres_porquinhos_estilo_peppa_youtube.mp4`
- `output/tres_porquinhos_estilo_peppa_tiktok.mp4`
- `output/vozes_personagens.mp3`

## Nota
Designs originais inspirados no *estilo* de produção pré-escolar flat 2D — **não** é Peppa Pig nem usa marcas/personagens da franquia.
